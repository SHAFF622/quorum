# Quorum: a referee panel for AI-scientist claims

Quorum blind-checks claims made by AI scientists (such as Kosmos) against public breast-cancer
data (METABRIC and TCGA via cBioPortal), and labels each claim verified, contested or rejected.

- `quorum/`: the code, tests and how to run it (see `quorum/README.md`)
- `site/quorum.html`: the one-page site

The open-source Kosmos used as a claim generator is not included here; it lives at
https://github.com/jimmc414/Kosmos.
